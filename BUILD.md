# Сборка и установка

## GitHub Actions

Проект уже содержит `.github/workflows/build-apk.yml`.

1. Распакуйте архив.
2. Загрузите **содержимое папки проекта**, включая скрытую `.github`, в репозиторий GitHub.
3. Откройте вкладку **Actions**.
4. Выберите **Build Android APK** и запустите workflow.
5. После зелёной галочки откройте запуск и скачайте artifact **Cytisine-APK**.
6. Распакуйте artifact и установите `Cytisine.apk` на Android.

В проект включён отдельный тестовый keystore только для этой личной debug-сборки, поэтому все последующие APK из этого проекта подписываются одним и тем же ключом и смогут обновлять друг друга. Старая версия, собранная предыдущим workflow с другим ключом, может потребовать одноразового удаления перед установкой v1.3. Этот ключ не предназначен для публикации в Google Play.

## После установки

1. Разрешите уведомления.
2. Разрешите **«Будильники и напоминания»**.
3. На Android 14+ при необходимости разрешите полноэкранные уведомления для будильника.
4. В настройках батареи телефона для «Цитизин» выберите режим без ограничений, если такая опция есть у производителя.
5. Откройте приложение и снова нажмите **«Сохранить и включить будильники»**.
6. После следующего сигнала посмотрите блок **«Последний сигнал»**: он покажет фактическую задержку в секундах.
