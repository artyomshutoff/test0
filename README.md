# Цитизин — Android

Версия 1.3. Локальный будильник по 25-дневной схеме приёма цитизина.

## Что изменено в 1.3

- Основной сигнал планируется через `AlarmManager.setAlarmClock()`.
- `AlarmManager` запускает foreground-service будильника напрямую, без промежуточного BroadcastReceiver.
- Убрано перепланирование всех сигналов при каждом открытии главного экрана.
- Отмеченный как принятый приём теперь отменяет и основной, и отложенный сигнал.
- При полном перепланировании отменяются также старые snooze-сигналы.
- Добавлена 2-минутная grace-зона после перезагрузки/смены времени, чтобы сигнал около системного события не потерялся.
- Foreground service помечен как `systemExempted` для сценария точных будильников Android 14+.
- Пока будильник звонит, сервис держит ограниченный по времени partial wake lock.
- На главном экране отображается диагностика последнего сигнала: плановое время, фактический запуск и отклонение в секундах.
- Есть экран проверки разрешения точных будильников, full-screen intent и настроек энергосбережения.
- В проект добавлен постоянный тестовый signing key, чтобы будущие GitHub Actions APK обновляли приложение без смены подписи.

## Важно

Это приложение является только средством напоминания и не заменяет инструкцию к конкретному препарату или назначение врача.

## Сборка через GitHub Actions

Workflow находится в `.github/workflows/build-apk.yml`.

1. Загрузите содержимое проекта в репозиторий GitHub.
2. Откройте **Actions → Build Android APK**.
3. Нажмите **Run workflow**.
4. После успешной сборки скачайте artifact **Cytisine-APK**.
5. Внутри будет `Cytisine.apk`.

После обновления APK откройте приложение, нажмите **«Сохранить и включить будильники»** и проверьте блок **«Надёжность будильников»**.
