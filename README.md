# Цитизин — Android reminder

Небольшое локальное приложение для напоминаний по 25-дневной схеме приёма цитизина 1,5 мг.

## Что умеет
- выбор даты начала курса и времени первого приёма;
- формирование 25-дневного расписания;
- локальные уведомления без сервера и регистрации;
- отметка каждого приёма как выполненного;
- восстановление напоминаний после перезагрузки телефона;
- запрос разрешения на уведомления Android 13+;
- возможность включить точные будильники Android 12+.

## Важно
Приложение — только техническое напоминание. Оно не назначает лечение. Перед использованием сверяйте схему с инструкцией к вашему конкретному препарату и назначением врача.

## Версия 1.1 — звуковые будильники
Теперь в момент приёма запускается полноценный звуковой будильник: звук повторяется до действия пользователя, включается вибрация и показывается экран будильника поверх экрана блокировки (если Android разрешает полноэкранные уведомления). Есть кнопки «Принято» и «Отложить на 5 минут».

На Android 12+ обязательно разрешите приложению точные будильники. На Android 13+ разрешите уведомления. На новых версиях Android полноэкранный экран будильника также зависит от системного разрешения полноэкранных уведомлений; даже без него звуковой будильник продолжит работать через foreground service.
